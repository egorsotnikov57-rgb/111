### Что такое циклы в программировании?

Цикл - это управляющая конструкция, которая позволяет многократно повторять один и тот же блок команд до тех пор, пока выполняется определённое условие или пока не будет выполнено заданное количество повторений.

Зачем нужны циклы:
В жизни мы постоянно сталкиваемся с повторяющимися действиями. В программировании, если нужно выполнить одно и то же действие много раз, вместо того чтобы писать один и тот же код снова и снова, мы используем цикл.

### Виды циклов

| характеристика      | Цикл for                                                                                                                                   | Цикл while                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| Функция(назначение) | Повторение кода **известное количество раз** или перебор элементов коллекции (строки, списка). Быстрый по любому нтерпретируемому объекту. | Повторение до **тех пор, пока условие истинно** (количество повторений заранее неизвестно). |
| Когда использовать  | Когда мы точно знаем, сколько раз нужно повторить действе, или нужно пройтись по всем элементам.                                           | Когда мы не знаем точного количества повторений, но условие остановки.                      |
| Синтаксис           | for переменная in    последовательность:                          тело цикла                                                               | while (условие):                 тело цикла                                                 |
| Проверка условия    | Перед каждой итерацией (перед каждым проходом).                                                                                            | Перед каждой итерацией.                                                                     |
| Управление          | Счетчик автоматически берёт следующие значение из последовательности.                                                                      | Нужно самим изменять переменную внутри цикла, чтобы условие когда-нибудь стало ложным.      |
#### Оператор continue 
Оператор continue начинает следующий проход цикла, минуя оставшееся тело цикла(for или while)
Пример:
`python`
`or I in 'Hello, world':`
	`if I == "o":`
		`continue`
	'print(I * 2, end="")

#### Оператор break

Оператор break досрочно прерывает цикл.
`For in 'Hello, world`:
	`if I == 'o'`
		`break`
	`print(I * 2, end="")`

#### Оператор Else

Слово else, примененное в цикле for или while, проверяет, был ли произведен выход из цикла инструкцией break, или же "естественным" образом. Блок инструкций внутри else выполнится только в том случае, если выход из цикла произошел без помощи break.

Пример: 

`For in 'Hello, world!':`
	`if I == 'i':`
		`break`
`Else:`
	`print('Буквы i в строке нет!')`
